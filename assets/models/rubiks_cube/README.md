# Rubik’s cube

57 mm cube, mass 100 g, six colored 3 × 3 faces, friction and box collision. Self-contained SDF geometry; no external textures. A single rigid grasping object; the layers do not turn. Origin is at its center: place at surface height + 0.0286 m.

Add `/home/ws/assets/models` to Gazebo's resource paths in the project container, then insert `model://rubiks_cube`, or select `model.sdf` using Gazebo's Resource Spawner.
